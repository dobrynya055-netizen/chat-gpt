# Upstream skills and provenance

This repository currently stores original project-specific instructions, not full mirrored third-party skills.

- Anthropic frontend-design: https://github.com/anthropics/skills/tree/main/skills/frontend-design — inspiration for intentional brand-grounded visual design; review upstream license before copying.
- Vercel agent-skills: https://github.com/vercel-labs/agent-skills — reference for React/Next.js performance and component composition; repository README states MIT license.
- Emil Kowalski skills: https://github.com/emilkowalski/skills — candidate for future motion guidance; inspect specific files and licenses before importing.

When importing a third-party skill, preserve its license and attribution, record commit SHA and source path, and review executable scripts before running them. No third-party scripts are included here.
