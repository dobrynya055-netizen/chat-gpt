# Frontend Design
1. Identify audience, business goal, brand constraints and real content before coding.
2. Establish visual direction: type scale, palette, spacing, image treatment and layout rhythm.
3. Prioritize clear hierarchy, readable typography and deliberate negative space.
4. Build responsive mobile, tablet and desktop layouts; avoid cropping important subjects.
5. Preserve user-approved sections exactly unless a change is explicitly requested.
6. Review actual screenshots at common viewport sizes before delivery.
7. Deliver a runnable artifact, not only a visual mockup.
