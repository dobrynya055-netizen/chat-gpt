# Motion Design
Animate state changes and key storytelling moments, not every element. Use CSS for simple transitions; use Motion or GSAP only when complexity justifies it. Prefer transform and opacity; avoid layout thrashing. Respect prefers-reduced-motion. Verify keyboard interaction, scroll behavior, mobile performance and no content shifts. Keep animations interruptible and avoid scroll hijacking.
