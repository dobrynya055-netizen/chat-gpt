# React Performance
Avoid sequential independent fetches, oversized client bundles, unnecessary re-renders and unoptimized images. Validate server/client boundaries, cache behavior and accessibility. Measure with Lighthouse and browser profiling before claiming improvements. Reference the original Vercel guidance: https://github.com/vercel-labs/agent-skills .
