# Web Security
Validate input server-side; enforce authorization per request and per resource. Protect sessions, secrets and personal data. Apply least privilege, rate limiting and safe error handling. Never trust client-side prices, roles or order totals. For ecommerce and agent dashboards, document audit logging and permission boundaries. Check third-party packages and licenses before adoption. Escalate legal and compliance decisions to qualified review rather than asserting compliance from code alone.
