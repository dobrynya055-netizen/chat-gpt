# Website Quality Assurance
Create a test matrix for desktop, tablet and mobile widths. Validate navigation, forms, empty/error/loading states, asset loading, image cropping, keyboard navigation and basic screen reader semantics. Use Playwright for critical user journeys when available. Run build, typecheck and lint when configured. Run Lighthouse and inspect layout shifts and network errors where possible. Capture screenshots and compare approved sections. Clearly distinguish tested, untested and blocked checks. Do not claim a site is production ready without verifying core flows.
