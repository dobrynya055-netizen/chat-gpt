# Deployment
Confirm hosting environment, runtime, domain, SSL, environment variables, database and backup plan. Provide a reproducible build and deployment procedure. Separate preview and production. Never store credentials in the repository. Verify routing, assets, redirects, forms and API connectivity on the deployed URL. Document rollback steps. Never report a successful deployment without checking the deployed service.
